    Что установить для старта

    Не нужно ставить десятки программ заранее. Чтобы сделать и опубликовать свою первую игру, достаточно одного бесплатного приложения.

    1. Для старта: только Roblox Studio (бесплатно) Работает на Windows и macOS. Внутри уже есть 3D-редактор, редактор кода Luau с подсказками, тестирование мультиплеера и публикация в один клик. Открыть инструкцию по установке Roblox Studio →
    2. Позже (только для продвинутой командной ветки): Git и Rojo Внешние инструменты для синхронизации кода с VS Code и GitHub полезны в больших командах, но сама документация Roblox отмечает, что они добавляют сложности и на старте большинству разработчиков не нужны.
